    0.17.0 (2026-08-23)

    Features

    • cli: add the policy init command (fef0667)
    • policy: manifest-introspecting policy scaffold generator (c0b01df)
    • cli: add the policy test command (1f932ee)
    • models: add policy-init scaffold report schema (e163def)
    • display: render the policy-test backtest report (92e32a2)
    • backtest: replay a policy over changesets with per-rule aggregation (1c9f23e)
    • changeset: load changesets from json and add git-range helpers (46cfd35)
    • models: add backtest result schema (b706f2e)
    • display: render applied and ineffective overrides in the report (f9a633d)
    • policy: cap policy rule hits with matching overrides (86ed5cd)
    • verdict: honor overrides in the gate ruling (a1043b6)
    • changeset: attach override directives to column changes (2a9c0f3)
    • parser: parse -- lineage:allow-change/allow-break pragmas (4d1e296)
    • models: add override directive and rule-hit override fields (a7ddaa0)
    • policy: add built-in semantic-severity gate knobs (07ae7fb)
    • verdict: let the semantic axis lift a safe ruling to review (7035986)
    • impact: add --explain to surface why each column was flagged (400e2f6)
